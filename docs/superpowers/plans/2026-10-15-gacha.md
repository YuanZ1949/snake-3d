# 抽卡（祈愿）系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为贪吃蛇游戏加入原神式祈愿抽卡：吃果星尘双轨货币、原神概率保底、CSS 流星动画、11 款程序化新皮肤（含 5星流光特效）。

**Architecture:** 服务端 serve.py 负责全部权威状态（星尘余额、库存、保底计数、概率判定），新增纯函数 `gacha_roll`（rng 可注入）+ 两条消息 `gacha`/`gachainfo`；客户端 index.html 扩充 SKINS 数组、新增祈愿全屏覆盖层（CSS 流星 → 爆闪 → 卡片翻出）与 canvas 立绘卡。单文件架构不重构。

**Tech Stack:** Python 3 + asyncio WebSocket（既有）；原生 JS/CSS/Canvas（既有）；无新依赖。

**Spec:** `docs/superpowers/specs/2026-10-15-gacha-design.md`（本计划的每个数值以 spec 为准；本修订版对 spec §5.2/§5.3 的协议字段有两处已声明偏离，见 Global Constraints 末条）

**审查状态：** 已经 oracle 子代理审查（FAIL → 按 2 BLOCKER + 9 MAJOR 全部修订入本版）。

## Global Constraints
- 概率/余额/保底/库存全部服务端判定，客户端消息不可信；客户端只播动画。
- **入参白名单**：`gacha` 的 `n` 必须 `in (1, 10)`，否则回 error（余额/库存/保底一律不动）；`skin` 的 `i` 与所有 `int()` 转换一律 try/except，非法值回 error 或回退（各消息在任务内写死），**禁止异常被顶层吞掉导致无回包**。
- **身份一致性**：`gacha/gachainfo/skin` 均要求 `sess.user and sess.user == p.get('user')`（入局时 `p['user']` 冻结），不一致按未登录回 error（防中途换号跨账号搬资产）。
- **扣减原子性**：余额检查 → 扣减 → 保底落库之间不得 await（先算后发）。
- Store users JSON 新字段一律防御式读取（`u.get(key, default)`），旧账号无缝兼容。`add_stardust` 结果钳制非负（`max(0, ...)` 兜底）。
- **皮肤 id 归一化先于鉴权**：`i = int(...)` try/except 回 0 → `i %= 16`（SKINS 总长）→ `if i >= 5 and i not in store.skins_of(sess.user): error`。`skin` 消息未拥有回 error 且 `p['skin']` 不变；**join 处越界/未拥有一律静默回退 0 不拒绝**（皮肤可降级展示，防 localStorage 残留锁死进房）。
- 现有 5 款免费皮肤（SKINS 下标 0-4）永不需拥有、不受鉴权限制；**免费 5 款 `star: 3`**（皮肤页签分组需要）。
- 新皮肤 id 分配：5-10 = 3★×6（赤霞/青岚/墨影/鎏银/樱粉/沙金）、11-13 = 4★×3（星河/雷纹/霜纹）、14 = 5★常驻白金圣蛇、15 = 5★UP 辉夜。
- 数值（verbatim from spec，含 Task 0 经济拍板）：5★1.6%、硬保底 90、50/50 大保底；4★13%、10 抽必出；定价 160/抽、1600/十连；重复返还 3★10/4★50/5★200；**吃果当场星尘 +10（普通果与 bonus 星星都 +10；场上多果并存，果数 3-8 随地图放大）**，局末/死亡/离房 1:1 入总账。
- 未登录：可显示当场星尘但不可抽（gacha 回 error 引导登录）；死亡/离房时未登录的当场星尘直接丢弃。
- **大厅（无房间）允许抽卡**：`p` 可能为 None，dust 按 0 计；不得空引用。
- 门禁：`.venv\Scripts\python.exe test_game.py` 全绿（当前 111 起）、`node C:\Users\yuan\AppData\Local\Temp\opencode\static_check.js index.html` 全绿（当前 js=581 起）、`pwsh scripts\local_ci.ps1` ALL GREEN。
- 探针/取证脚本放 `test-results/`，跑 local_ci 前备份到 `C:\Users\yuan\AppData\Local\Temp\opencode\`。
- 提交：`git add` 后直接 `git commit`（默认 autocrlf 归一），真账看 `git show --numstat`。
- **（已声明的 spec 偏离，完工时回写 spec）**：①回包字段用 `balance`(纯总账)+`dust` 分列而非 spec 的"balance 含当场"，另附 `gained`(本次总扣减)；②`gacha_roll` 为 4 参，皮肤映射独立为 `pool_pick(rng, star, up)`（可打桩）。
